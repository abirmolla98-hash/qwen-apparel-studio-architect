# Qwen Apparel Studio Architect 🎨🤖

A local-first AI Creative Direction engine powered by **Qwen 2.5** and **Ollama**. It transforms raw e-commerce apparel specifications into structured, production-ready fashion photography prompts using a deterministic 7-stage visual architecture, supporting both single execution and automated batch processing.

## 📐 Architecture Sequence
Every creative concept is engineered through a strict pipeline:
`Product` → `Model` → `Form` → `Pattern` → `Lighting` → `Brand Emotion` → `Conversion`
